# Mi primer proyecto con Codex

## Descripción

Este proyecto es una página web sencilla creada como práctica inicial para aprender a trabajar con Codex, VS Code, Git, HTML, CSS y JavaScript.

El objetivo principal no es crear una página compleja, sino aprender el flujo profesional básico de desarrollo: crear archivos, modificar código, probar cambios, revisar diferencias con Git y guardar versiones mediante commits.

## Objetivo de aprendizaje

Este proyecto me ayuda a practicar:

* Cómo organizar un proyecto web básico.
* Cómo conectar HTML, CSS y JavaScript.
* Cómo usar Codex como apoyo para crear, revisar y diagnosticar código.
* Cómo usar Git para guardar versiones del proyecto.
* Cómo revisar cambios antes de hacer commit.
* Cómo corregir errores de forma controlada.

## Funcionalidades

La página incluye:

* Un título principal.
* Un párrafo introductorio.
* Una sección de conceptos aprendidos.
* Una sección llamada “Mi progreso”.
* Un botón “Cambiar texto”.
* Un botón “Reiniciar texto”.

El botón “Cambiar texto” modifica el mensaje principal de la página.

El botón “Reiniciar texto” devuelve el mensaje a su texto original.

## Cómo abrir el proyecto

Para abrir el proyecto en el navegador desde PowerShell, se puede usar:

```powershell
start index.html
```

También se puede abrir manualmente haciendo doble clic sobre el archivo `index.html`.

## Comandos Git aprendidos

Durante este proyecto se practicaron comandos básicos de Git:

```powershell
git status
```

Muestra el estado actual del proyecto.

```powershell
git diff
```

Muestra los cambios realizados antes de guardarlos.

```powershell
git add archivo
```

Prepara archivos para el próximo commit.

```powershell
git commit -m "mensaje"
```

Guarda una versión del proyecto con una descripción.

```powershell
git log --oneline
```

Muestra el historial resumido de commits.
